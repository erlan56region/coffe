# coffeeIT — 5 вариантов сайта

Пять самостоятельных автономных сайтов бренда **coffeeIT** (кофейня × пространство для разработчиков × IT-интегратор).

**Живая версия:** `https://<ваш-логин>.github.io/<имя-репозитория>/`  
(после включения GitHub Pages — см. «Публикация» ниже)

| Файл | Вариант | Стиль | Кому |
|---|---|---|---|
| `coffeeit-v1.html` | «Код и зерно» | светлый кремовый, антиква, тёмно-зелёный, редакционная сетка | премиум-клиенты, студийная подача |
| `coffeeit-v2.html` | «Смена» | тёмный графит + неоновый лайм, стеклянные панели, карусель услуг | digital-аудитория |
| `coffeeit-v3.html` | «Coffee first» | нео-брутализм: молочный фон, толстые контуры, оранжевый, стикеры | молодёжь, максимум характера |
| `coffeeit-v4.html` | «Terminal» | моно-шрифт, консоль, YAML-блоки, таблицы-«базы данных» | инженеры и разработчики |
| `coffeeit-v5.html` | «Build & Brew» | серо-стальной корпоративный: таблицы с ценами, вкладки, FAQ | B2B-закупки |

`index.html` — страница-навигатор по всем пяти вариантам (с мини-превью).

## Что внутри каждого варианта

- 7 «страниц» в одном файле без перезагрузки: Главная, Услуги, Кейсы, Вендоры, Пространство, Мерч, Контакты;
- логотип-кружка в стиле варианта, адаптив под телефон, анимации появления, счётчики;
- 5 IT-услуг (разработка, закупка серверов/СХД/лицензий, ИБ, интеграции, инфраструктура);
- 6 кейсов с метриками, раскрывающимися подробностями и фильтром по направлению;
- 16 вендоров, кофейное меню, зоны пространства и бронирование;
- магазин мерча: 23 товара, фильтры, корзина с сохранением после перезагрузки, оформление заказа письмом;
- формы заявок через почтовое приложение — без сервера;
- всё встроено: CSS, JS, логотип, иллюстрации, фотографии, шрифты. Внешних CDN нет — работает офлайн.

## Публикация на GitHub Pages (2 минуты)

1. Создайте репозиторий: https://github.com/new → имя, например `coffeeit`, **Public**, без README и лицензии.
2. На странице пустого репозитория нажмите **«uploading an existing file»**.
3. Распакуйте архив `coffeeit-github.zip` и перетащите в окно браузера **всё содержимое папки** (файлы `index.html`, `coffeeit-v1…v5.html`, `README.md`, `.nojekyll` и папку `source`).
4. **Commit changes**.
5. Settings → **Pages** → Source: **Deploy from a branch** → Branch: `main`, Folder: `/ (root)` → **Save**.
6. Через 30–60 секунд сайт откроется: `https://<логин>.github.io/coffeeit/`

> `.nojekyll` уже лежит в архиве — он нужен, чтобы GitHub Pages отдавал файлы как есть, без обработки Jekyll.
> Файлы крупные (≈450 КБ каждый — внутри фотографии), но лимит GitHub в 100 МБ на файл далеко.

### Через терминал (если удобнее)

```bash
cd coffeeit                       # распакованная папка
git init -b main
git add -A
git commit -m "coffeeIT: 5 вариантов сайта"
git remote add origin https://github.com/<логин>/coffeeit.git
git push -u origin main
```

## Правка контента

Контакты, услуги, кейсы, цены, товары и меню живут в одном объекте `window.CI_DATA` в начале каждого HTML-файла — правится в блокноте, без сборки.

Если нужны исходники: папка `source/` — там `build.py`, стили и скрипты всех вариантов, фотографии:

```bash
cd source
python3 build.py            # пересобрать все пять вариантов
python3 build.py v3         # только третий
```

⚠️ Перед публикацией замените демонстрационные контакты, адрес, цены и кейсы на реальные — сейчас это примеры.
